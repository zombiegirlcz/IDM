 Properties Dialog
 "Properties" dialog is shown up when you pick "Properties" item in the download pop-up menu or when you double click on the file name in IDM main dialog.
 This dialog shows download information and let you change file location on the hard disk, Internet file URL and description. You can execute files by clicking on "Open" button.
