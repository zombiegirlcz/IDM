 Quick Update
 Quick Update
 IDM checks for newer releases on its home site once per week and suggests updating when a new version becomes available.
 [IMG: IDM new version is available]
 Update dialog asks if you want to update IDM showing all enhancements of the new version and the date of the new release. Press "Update now" to install the latest version.
 You can also check for a newer version using "Help→Check for updates..." IDM main menu.
